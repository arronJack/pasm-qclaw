# 浏览器自动化连接器

## 目标
把"在浏览器里做事"变成可执行能力：用户说"打开XX网页/在浏览器里搜XX/网页截图"，PASM 真的驱动浏览器完成。

## 何时使用
- 用户说"打开百度 / 访问 github.com / 在浏览器里搜一下XX"。
- 需要在网页里**动手**：点击某个链接/按钮、在输入框填内容、滚动加载、抽取信息、截图。
- 多个动作可写在一句里，如"打开某站，点击登录，在用户名输入 abc"。
- 对比"只给步骤"的传统 AI：这里**直接动手**。

## 接入方式（内置）
- 基于 Playwright 驱动浏览器：**优先复用系统自带的 Edge / Chrome（免下载 150MB Chromium）**，
  失败再退回 Playwright 自带 Chromium；未安装 Playwright 时给出明确安装指引，不崩溃。
- 默认有头模式（用户能看到浏览器被操作）；可在设置里开 `browser_headless` 转无头。
- 敏感操作（登录/填密码）务必先向用户确认，绝不静默代入凭据。

## 输出结构
- 完成动作 + 页面标题
- 截图路径（用户可直接看）
- 页面要点摘要

## 质量红线
- 无法操作/被拦截要明说，不谎称"已打开"。
- 登录/支付等高风险动作需用户确认；不记录密码。
