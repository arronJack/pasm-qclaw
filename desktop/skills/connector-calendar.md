# 日历连接器（connector_calendar）

## 这个技能给你什么
PASM 能记住你的日程，并按天给你列出安排。用的是**标准 iCalendar (.ics)** 格式，
所以这份日历能直接拖进 Google 日历 / 手机日历，也能反过来导入别人的 .ics。

## 它跑在什么之上
基座 `pasm-skills`；实现是 `desktop/connector_calendar.py`（手写 ICS 读写，零新依赖）。

## 与"定时提醒"的分工（别混）
- **日历** = 记「什么时候有什么事」——可导出、可分享、可看一周安排；
- **定时任务** = 让 PASM「到点自己动起来」——提醒你、跑技能、推手机。

## 执行步骤
1. **建日程**：「明天下午 3 点开会」→ 解析时间 + 标题，写入 `calendar.ics`。
2. **重复日程**：「每周一 9 点开周会」→ 写成带 `RRULE:FREQ=WEEKLY` 的标准重复事件。
3. **看安排**：「我最近有什么日程」→ 按天分组列出（今/明/周X）。
4. **导入**：`import_ics(path)` 可把 Google/Outlook 导出的 .ics 合并进来（按 UID 去重）。

## 输出结构
· 建成功：确认标题 + 时间 + 落盘文件名
· 列表：`【09-15 明天】` 分组，每项 `HH:MM 标题`，重复日程标 🔁

## 质量红线
- 解析不出时间**必须反问**，不许建一个猜出来的日程。
- 「会议纪要 / 会议记录 / 会议材料」是**文档**不是日程，不能被判成建日程。
- 写文件用「临时文件 + 原子替换」，断电不丢旧日历。
