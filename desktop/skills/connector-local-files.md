# 本地文件与应用连接器

## 目标
把"这台电脑上的东西"变成可调用的外部能力：读、找、开、写，全都真实落地到用户磁盘。

## 何时使用
- 用户给路径或文件名（读一下 / 找一下 / 打开 / 分析一下某文件）。
- 开发/写码需要把结果存成真实文件。
- 用户要打开某个应用、文件夹、文档。

## 接入方式（内置）
1. 读文件：txt/md/json/py/csv/docx/xlsx/html/pdf 等，读入后内容进入工作上下文。
2. 找文件：说关键词即可在用户目录/指定目录检索。
3. 打开：应用名或路径 → 系统方式真实打开（应用会出现在屏幕，绝不在文本里假装"已打开"）。
4. 写文件：脚本/项目/文档按用户选择的目标目录落盘，落盘后告知完整路径。

## 输出结构
读：读了什么/能做什么的摘要；开：真实打开并确认；写：文件清单与完整路径

## 质量红线
- 写文件前确认落点目录；不覆盖用户没授权的现有文件。
- 声称"已打开/已生成"前必须真的执行成功。
