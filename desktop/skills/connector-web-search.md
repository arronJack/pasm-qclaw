# 联网检索连接器

## 目标
把"搜网络"变成可调用的外部能力：一句话明确要查的主题，即可多源抓取并整理。

## 何时使用
- 用户说"上网学 / 查一下 / 搜一下 / 帮我找找最新 / 这个说法对不对（需要外部验证）"。
- 知识库缺新信息、或事实随时间变化（价格/政策/赛事/版本）。

## 接入方式（内置）
1. 主题太泛时先窄化：把"查一下基金"扩成"查一下 2024 年后的 A 股基金定投收益率表现"。
2. 抓取结果先提炼要点，原文全文存知识库，聊天里引述时标注来源时间。
3. 学到的内容沉淀成技能/知识条目，之后相关提问自动引用。

## 输出结构
要点 3-8 条（每条可复述、带来源）＋ 存入知识库的确认

## 质量红线
- 抓不到/被拦截要明说，不编造"网上的说法"。
- 敏感或时效信息标注"截至查询时间"。
- 一次只学一个主题，不把多主题揉在一起。
