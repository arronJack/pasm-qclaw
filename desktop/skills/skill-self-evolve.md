# 自进化：把经验沉淀成技能（self_evolve）

## 这个技能给你什么
PASM 干完一件事，可以把这次的**做法**固化成一份技能卡 —— 下次同类活不用重新教，
它自己就按上次的标准做。这就是"越用越顺手"。

## 它跑在什么之上
基座 `pasm-skills`；实现是 `desktop/self_evolve.py`，产出物是标准 SKILL.md，
直接进技能库（`skillstore`），立刻可被检索与复用。

## 执行步骤
1. **复盘**：从工作台账里捞一条已完成的任务（含产出、附件、过程记录）。
2. **提炼**：套标准结构写成正文 —— 目标 / 何时使用 / 执行步骤 / 输出结构 / 质量红线。
   有模型可用时让它润色；没有模型时用结构化模板。
3. **入库**：以「自进化·<名字>」写入用户技能库，并给出触发词。
4. **主动建议**：扫台账，发现某类活**重复成功 ≥2 次**就提示"要不要沉淀成技能？"

## 输出结构
· 沉淀成功：技能名 + 触发词 + 落盘路径 + 一句"想改随时说"
· 建议：「📈 这几类活你干过好几次了…」列表
· 素材不足：如实说"台账里还没找到已完成的工作"，不硬凑

## 质量红线
- **绝不编造用户没做过的步骤** —— 宁可步骤少而真。两种提炼路径都守这条。
- 沉淀的是**做法**，不是结果文件；不把用户数据/密钥写进技能正文。
- 技能正文不含内部路径等隐私信息，保证可以安全导出分享。
