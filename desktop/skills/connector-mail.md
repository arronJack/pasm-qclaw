# 邮件连接器（connector_mail）

## 这个技能给你什么
PASM 能**真的收发你的邮件**：读未读、按关键词搜、按你说的收件人/主题/正文发出去。
不是给你一段"你可以这样写"的模板，是真的连上邮箱干活。

## 它跑在什么之上
基座 `pasm-skills`；实现是 `desktop/connector_mail.py`（标准库 `imaplib`/`smtplib`/`email`，零新依赖）。

## 配置（设置 → 连接器 → 邮件）
| 项 | 说明 |
|---|---|
| mail_user | 你的邮箱地址（也是默认发件人） |
| mail_pass | **授权码 / 应用专用密码**（不是登录密码！） |
| mail_imap_host / mail_smtp_host | 留空则按域名自动识别（QQ/163/Gmail/Outlook/阿里企业邮都会认） |

## 执行步骤
1. **看邮件**：「看看我的邮件」→ 取最近 5 封未读，给出主题/发件人/正文摘要。
2. **搜邮件**：「搜一下含报价的邮件」→ 先按主题搜，没有再按全文搜。
3. **发邮件**：「给 a@b.com 发邮件，主题是周报，内容是……」→ 直接发出。

## 输出结构
· 列表型：编号 + 主题 + 发件人 + 摘要
· 发送型：明确的「已发送 ✅ → 收件人（主题）」
· 未配置：给出中文配置指引，**绝不假装已发送**

## 质量红线
- 缺收件人 / 缺正文时**必须反问补齐**，不许编一个地址或正文发出去。
- 授权码以明文存本机 config.json（与主流桌面客户端一致），不写进日志、不回显。
- 网络失败 / 认证失败一律给中文原因（尤其"把登录密码当授权码"这个最常见错因）。
