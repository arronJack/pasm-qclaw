# 实时天气连接器

## 目标
把"查天气"变成一句话直接回答的真实能力：用户问某地天气，给出当前气温、天气状况、湿度风速与未来几日预报。

## 何时使用
- 用户说"XX 天气怎么样 / 今天气温多少 / 明天会下雨吗 / 周末适合出门吗"。
- 需要结合天气给建议（穿衣、出行）时。

## 接入方式（内置）
- 走 open-meteo 免费接口（地理编码 + 预报），免 token、全球可用。
- 直接给答案，**不打开浏览器**；网络失败会如实说明，不编造数据。

## 输出结构
- 一行定位（城市/地区）
- 当前：气温 + 天气 + 湿度/风速
- 未来几天：日期 + 天气 + 温度区间

## 质量红线
- 查不到城市/网络失败要明说，绝不编造"今天 25 度"这类没有来源的数字。
- 时效信息默认"当前查询时刻"。
