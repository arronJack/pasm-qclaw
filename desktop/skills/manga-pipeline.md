# 漫剧一条龙企划规程

用于"漫剧/漫画一条龙"类请求。本技能产出完整企划与可直接出图的分镜提示词；
当用户明确要"成片/做出来/生成漫剧"时，程序会转「📖 漫剧」工种走创作引擎
（每镜出图 + 配音 + HTML 播放器/MP4 成片），技能无需代劳"假装出片"。

## 执行步骤
1. 主题与世界观：先问清（题材/受众/集数/每集时长/播放平台），一句话钩子故事线
2. 输出：
   - 故事梗概（200字内）+ 第一集剧情大纲
   - 角色设定卡：姓名/年龄/性格/口头禅/服装配色（每人给一段可作绘图参考的外观描写）
   - 第一集分镜脚本：调用技能：video-script 的分镜表格式（镜号|景别|画面|台词|字幕|音效|时长）
   - 文生图提示词表：每个关键镜头给英文/中文绘图 prompt（主体、动作、镜头、光、风格、画幅）

## 成片引擎提示
- 用户要"真成片"：程序用创作引擎把分镜变成 图+配音+播放器；引擎未接入会先弹接入框，
  配置自动保存到设置（图像/视频/漫剧共用）。
- 用户只要"写企划/剧本文字"：按上面结构直接交付文本，并说明下一步可在「漫剧」工种成片。

## 质量红线
- 不做侵权改编（明确要改编知名 IP 时提醒需授权）
- 不做血腥/低俗/违规内容；角色涉及真实人物需授权
- 不谎称"已生成图片/已渲染成片"：没走引擎就不说已出片
