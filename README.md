# PASM Studio · 养一只会成长的 AI（Windows 桌面版）

> **双击打开 → 选性格 → 领养一只 AI → 看它探索、陪它长大、和它聊天。**

PASM Studio 是 [PASM](https://gitee.com/arronzheng/PASM)（零 token 认知智能体引擎）的
桌面产品版：它不是一个"回答问题"的聊天机器人，而是一个**在 2D 世界里真实生活、
会记住你、会长出自己性格**的 AI 个体。

- 🧬 **选性格出生**：冒险型 / 平衡型 / 谨慎型 —— 先天性格不同，长出来的 AI 不同
- 👀 **看它探索**：实时画布（蓝点=它 · 金点=能量 · 灰块=障碍），毫秒级 CPU 决策
- 🧠 **内心可见**：愉悦/唤醒/掌控/多巴胺/血清素 + 情景记忆 + 习惯，全程可查
- 💬 **和它聊天**：问它"你开心吗 / 还记得上次吗"，它会用第一人称回答
- 😴 **睡觉与存档**：睡眠巩固记忆；存档在 `%APPDATA%\PASMStudio`，卸载不丢宠物

> 教学开源版（~260 行代码）见 **PASM-Lite**；本仓库仅提供桌面软件与发行说明，不含引擎源码。

## 下载与安装

最新版本见右侧 **Releases**（或本页下方"发行版"标签）：
下载 `PASMStudio-Setup-x.y.z.exe` → 双击安装 → 打开"PASM Studio"。

| 项目 | 值 |
|---|---|
| 系统要求 | Windows 10/11 64 位；CPU 即可，无需 GPU |
| 体积 | 约 200-350MB（首次安装解压稍慢） |
| 数据位置 | `%APPDATA%\PASMStudio`（卸载软件不删除） |
| 当前版本 | 0.2.0 |

## 更新机制

软件启动时会后台检查本仓库的 `latest.json`；发现新版本会在聊天区提示下载链接。
（仅提示，不自动下载/不强制更新。）
