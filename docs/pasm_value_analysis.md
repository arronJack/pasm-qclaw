## 二、市场坐标（2026-09 实况）

### 记忆中间件赛道（你的引擎层在这个赛道）

| 玩家 | 规模 | 架构路线 | 短板 |
|---|---|---|---|
| Mem0 | 61.2K★ · $24M 融资 · 15万开发者 | 被动抽取→向量库 | 记忆不会"因有用而变强" |
| Zep | Graphiti 开源 | 双时态知识图谱 | Fact Rating 已弃用，自托管版退役 |
| Letta | MemGPT 团队 | OS 式记忆分页 | 无任何结果反馈机制 |
| cognee | Apache 2.0 | 图谱文档管线 | 反馈默认关闭（权重 0.0） |

**关键调研发现（2026-09 独立评测的结论原话）："这里几乎没有人从错误中学习"**——
全行业没有任何一家做到了**"记忆因被验证有用而增强、因反复失败而衰减"的结果反馈闭环**。
Mem0 的 Memory Decay 只是定时器；Mnemoverse 的 valence 需要显式调用才生效。

### AI 伴侣赛道（你的产品层在这个赛道）

- 市场规模：2026 年 **$42 亿**，Character.AI 4500万 MAU，Replika 4200万用户/300万付费
- 行业共识：**"记忆就是产品"（Memory is the product）**——实测 Character.AI 三周后遗忘，Nomi 靠记忆领先
- **本地/离线是增长最快的细分**（NPU 普及、"数据主权"成为真实搜索词），但**原生桌面本地伴侣产品几乎空白**（唯一能打的 HammerAI 只有"本地跑模型"，没有认知引擎）
- 2027 前沿：具身伴侣（AR 眼镜/机器人/智能家居）

### 卡位结论

> PASM Studio 站在四条线的交叉空白点：**原生桌面 × 本地离线 × 真记忆/情感引擎 × 全栈干活**。
> 这四条每一单独都有人做，四条交叉目前市场上没有直接对手。

## 三、含金量评估（六维打分）

| 维度 | 评分 | 证据 |
|---|---|---|
| 差异化 | ★★★★★ | 零 token 认知循环 + 结果反馈记忆 + 量子策略，三层叙事无直接复刻者 |
| 工程完成度 | ★★★★☆ | 27 版迭代、214 冒烟、双端发布链全自动化；扣分：单人单机、无网络版 |
| 学术价值 | ★★★☆☆ | 消融初版有了；但缺可复现的公开 benchmark 和技术报告，"自证"不等于"公认" |
| 商业潜力 | ★★★☆☆ | 赛道 $4.2B 且教育场景（霖云智学桥接）是真需求；但 0 用户、0 收入、变现路径未验证 |
| 社区潜力 | ★★☆☆☆ | 引擎闭源，PASM-Lite 只是文档+250行教学码，社区基本盘还没有 |
| 抗风险 | ★★★★☆ | 本地离线天然规避记忆投毒（MINJA）和数据合规两大 2026 热点风险；大厂若做本地记忆会挤压 |

**总评：含金量 ≈ 「一级学术蓝海 + 二级半商业验证」。核心 IP 的稀缺性是真金，但金子还埋在土里——缺少"可证明性"（benchmark/论文）和"可传播性"（用户/社区）这两把铲子。**

### 五个真金点（值得守住的）

1. **结果反馈记忆**——全行业公认的空白（见二），你的衰减+巩固+RL+量子振幅回灌恰好是这条路，这是含金量最高的单点
2. **零 token 认知循环**——"AI 思考不一定要生成 token"这个命题本身就是论文级叙事，且工程上真的省成本、能离线
3. **情绪真正调制行为**——口吻注入、决策外场、TTS 情感化，不是贴纸式的"心情图标"
4. **完整数据闭环**——决策→执行→反馈→塑形，量子层的 observe/measure 与团队评分、RL 同构
5. **一个人跑通全生命周期**——从认知科学到 PyInstaller 打包到双仓运维，这个工程能力本身是复利资产

### 三个需要正视的短板

1. **没有裁判**：记忆赛道 benchmark 混战（同一数据集分数差 54 个百分点、全是厂商互咬），你自建的 evalkit 没有第三方公信力——好消息是：混战意味着"诚实、可复现的评测"本身就是稀缺品
2. **没有用户**：所有"感知得到记忆/情感"的证据都来自你自己，缺真实用户的行为数据
3. **融合还浅**：PASM 目前主要"调制"LLM（口吻/记忆注入/路由），还没做到"参与推理"（规划草图、世界模型模拟）——这是下一层含金量所在

## 四、发展方向（按含金量回报排序）

### P0 · 把含金量变成"可证明的"（最优先，1~2 个月）

1. **做一个诚实的公开 benchmark**：长对话记忆准确率（30/90 天跨会话）、token 节省率、情绪一致性、有/无 PASM 的回复质量对照——跑在 LoCoMo/LongMemEval 公开集上，哪怕分数不惊艳，"可复现 + 诚实方法论"在当前混战市场里就是稀缺品
2. **写一篇技术报告**（中文公众号 + arXiv 预印本）：《零 token 认知循环 + 结果反馈记忆：PASM 系统报告》——含金量的"证书"，也是招社区/用户的鱼饵
3. **强化消融实验**：同 prompt 下 PASM 开/关的对照（现在有了量子层的 observe 闭环，正好量化"经验让选路变准"的曲线）

### P0 · 把含金量变成"可传播的"（并行）

4. **开源认知皮层**：`cog.py + memory_layers.py + mathlab.py + quantum.py` 以 Apache 2.0 开一个独立仓（引擎核心仍闭源）——对标 cognee/Graphiti 的开源打法，换 GitHub 基本盘；这是三仓矩阵最缺的一块拼图
5. **PASM-Lite 桌面化**：把教学版做成一个 30MB 的极简桌面伴侣（Ollama + 分层记忆 + 情绪），免费投放收真实用户反馈——它就是产品的"免费试吃"

### P1 · 把认知循环做深（2~4 个月，护城河）

6. **世界模型"想象"**：LLM 回复前，PASM 在向量空间预演 2~3 个方案的后果（roadmap 里的 imagination 环节）——从"调制"升级为"参与推理"
7. **屏幕理解（B3/B4）**：定时截屏 → 本地视觉模型 → 知道你在干什么 → 主动帮忙——这是具身智能在 PC 上的最低成本入口，也是 2027 具身伴侣叙事的第一步
8. **语音输入闭环**：percept.transcribe 已就绪，接上按钮（挂着的任务 #20）——看+听+说齐了，"桌面小人"才算活了
9. **记忆安全治理**：给记忆写入加来源标记 + 写入审计（对齐 2026 记忆投毒议题），工程量小、叙事加分大

### P2 · 变现路径（4~6 个月，验证期）

10. **教育场景优先**：pasm-study-bridge → 霖云智学画像 v2 是你唯一已验证的 B 端真需求——"会记住学生弱点、情绪会陪伴的学伴"比通用伴侣好卖得多；先在 1~2 个真实学生/班级试用
11. **开源核心 + 商业引擎**双 license（cognee 模式）：个人免费、企业授权
12. **多用户网络版**：等有付费意向用户再做，别提前造

### 风险清单

- **大厂入场**：OpenAI/字节都在做记忆——护城河 = 本地 + 隐私 + 认知引擎深度（他们做不了"你的记忆强弱由你的成败塑形"这种个人化）
- **单点工程**：本地机器蓝屏频发 + 单人开发——冒烟体系已经救了你两次（回归抓档），继续保持"每版全绿才发"
- **合规**：教育场景涉及未成年人，情感陪伴功能要加"这是 AI"透明声明（对齐加州 SB243 同类要求，国内未成年人条例只会更严）
