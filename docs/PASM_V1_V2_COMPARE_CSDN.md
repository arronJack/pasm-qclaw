# PASM V1.0 与 V2.0 深度对比：从「仿生认知引擎」到「通用 AI 认知底座」

> 作者：arronZheng（小志） · 适用读者：AI 工程师 / 智能体开发者 / 对认知架构感兴趣的技术人
> 关键词：PASM、认知引擎、神经符号、象量空间、世界模型、双系统、诚实 AI

## 一、背景：为什么要做这次对比

PASM 是一套**通用 AI 认知引擎**。它不负责"写代码""画图"这种表面能力，而是给 AI 应用装上一套**认知器官**——记忆、世界模型、决策、情感偏置、安全边界——让应用从"会答话的壳"变成"会记住、会推演、会自我约束的智能体"。

在过去一年里，PASM 走完了两条版本轴：

- **V1.0** = 主仓 `pasm`（v0.7.x），定位**「仿生认知引擎」**：七层内部计算 + 一层认知执行皮层。
- **V2.0** = 独立包 `pasm2`（v2.0.0a11，阶段 0-11），定位**「通用 AI 认知底座」**：从仿生走向通用，19 层架构规划、象量连续空间、反事实推理、双系统门控。

本文用一张**维度对比表**先把差距摆出来，再逐项讲功能作用、用户价值、升级意义和它对未来 AI 发展的影响。文末附结论与选型建议。

## 二、核心维度对比表（一张图看懂 V1.0 → V2.0）

| 维度 | PASM V1.0（pasm 0.7.x） | PASM V2.0（pasm2 2.0.0a11） |
|------|--------------------------|-----------------------------|
| **产品定位** | 仿生认知引擎——给 AI 应用一层"认知器官" | 通用 AI 认知底座——"情感为核、逻辑为骨、语言为口、安全为界" |
| **架构形态** | 七层引擎（感知编码 / 向量记忆 / 世界模型 / 情绪动机 / 性格先验 / 元认知 / 全局工作空间）+ 认知执行皮层 | 19 层架构规划 + 阶段 0-11 递进（仿脑件 / 符号化 / 记忆图 / 反事实 / 双系统 / 量子 / 小脑 / DMN / 自传体） |
| **记忆系统** | 分层记忆：工作 / 情景 / 程序 / 语义印象 + 事实层（双时态三元组）；艾宾浩斯遗忘 + 重要度守恒 + 召回即巩固 | 象量连续潜向量（8 维 + 吸引子盆 + 情绪着色）+ 记忆图关联 + 睡眠重放（情绪优先 / 恶性合并检测）+ 自传体记忆 |
| **世界模型** | 符号世界模型：W1 动作后果表（Beta-Bernoulli + 层级贝叶斯回退）+ W2 rollout 脑内演练（条件独立假设） | 反事实推理（simulate / counterfactual / compare，"如果…会怎样"前向推演）+ 上下文预测器（象量级 next-entity，带奖赏预测误差 RPE）+ 小脑时序精修 |
| **决策机制** | `cog` 会话级状态机：意图 / 情绪姿态 / 话题惯性 / 目标 → 决策前缀（单步） | 双系统门控（System1 快直觉 / System2 慢深思）+ 量子叠加决策（叠加 / 退火 / 干涉 / 情绪外场 / 成败回灌）+ 岛叶躯体标记（gut feeling ∈ [-1,1] 偏置） |
| **符号推理** | 神经符号：`symbolic` / `ir` / `operators` / `planning` / `verifier` | 符号化梯度 + 三角校验 + 失衡监测 + SLH 单向桥（符号↔外部映射）+ 四路路由 + 数学脑 v2 |
| **安全机制** | 反幻觉相关性闸门（`touches_surface`）+ 前提一致性闸门（kind-aware） | 层 -2 安全层（价值锚点**不可修改**，常开）+ 象量安全维度（`safety_relevance` / `human_impact`）+ 诚实性纪律（证据不足如实拒绝、不编造轨迹） |
| **内感受 / 情感** | 情绪姿态（valence / arousal）偏置回复温度 | 岛叶内感受 → 躯体标记（能量 / 疲劳 / 压力 / 资源 → gut feeling），偏置决策与显著性评估 |
| **LLM 依赖** | 核心纯 stdlib 规则，断网可用；巩固 / 抽事实可用 LLM 但非必须 | 内核**零 token**（全部在连续潜向量空间完成，不产生文本）；纯 numpy，CPU 毫秒级，断网可用 |
| **工程纪律** | 单一真相源（薄壳再导出防分叉） | 契约先行 / 开关驱动 / 消融优先 / 异步写盘 / 可复现 / 回放验证；每加一层必须有开关 + 指标 + 收益；默认全关（诚实申报能力面） |
| **与产品耦合** | 桌面端单向（薄壳再导出） | 与 `pasm/` 完全独立包（单向隔离铁律，互不 import）；`CognitiveKit` 三档门面 + `CognitiveAssembler` 声明式装配 |
| **计算约束** | 规则 CPU 友好 | 严格守 CPU 毫秒级、可解释、契约稳定三条底线 |

## 三、逐维度功能作用详解

### 1. 定位：从「仿生」到「通用底座」
V1.0 的命题是"给 AI 应用认知器官"——它已经能记住用户、按情绪姿态回话、在脑内演练动作后果。V2.0 把命题抬高了一层：**认知器官不该绑定某一款产品，而应成为所有 AI 应用都能即插即用的"底座"**。所以它刻意做成独立包，不 import 主仓，也不被主仓 import，靠一份冻结的接口契约（`engine_api.py` 镜像，api 1.2）保持兼容。

### 2. 记忆：从「离散分层」到「连续空间自组织」
V1.0 的记忆是**符号化、离散、规则驱动**的：工作 / 情景 / 程序 / 语义四层 + 事实层（双时态三元组），靠艾宾浩斯曲线遗忘、靠重要度守恒防止重要记忆被琐事挤掉。它回答的是"该想起什么"。

V2.0 的记忆升级为**象量（entity）连续潜向量空间**：每条记忆是一个 8 维向量 + 吸引子盆 + 情绪着色，相似记忆自动聚成吸引子、共激活形成边，构成**记忆图**。更关键的是引入了**睡眠重放**——离线时按情绪优先级复盘、检测恶性合并、衰减淘汰。这让记忆从"被检索的档案"变成"会自我组织的神经网络"，并新增**自传体记忆**保证自我的时间连续性。

### 3. 世界模型：从「动作成功率估计」到「可推演因果」
V1.0 的世界模型是**符号 + 计数的贝叶斯**：W1 维护 (处境, 动作)→成功率的动作后果表（Beta-Bernoulli + 层级回退），W2 把一串动作连起来算期望成功率（rollout）。诚实但粗糙——它自己声明"假设各步条件独立，给的是可行性上界"。

V2.0 的世界模型进化为**反事实推理 + 上下文预测器**：`simulate()` 能从任意上下文种子出发按世界模型采样出"如果这么走会怎样"的轨迹，`counterfactual()` 对比"无干预基线"与"带干预"两条轨迹的偏离；`ContextPredictor` 用最近 K 个象量预测"下一步最可能激活什么"，预测错了会立刻产生**奖赏预测误差（RPE）**，被多巴胺通道和 ACC 直接消费——这正是认知层对应 LLM next-token 的"预测自洽"地基。

### 4. 决策：从「单步前缀」到「快慢双系统 + 叠加态」
V1.0 的 `cog` 是一个会话级状态机：识别意图、情绪姿态、话题惯性、正在推进的目标，产出一个"该怎么回话"的**决策前缀**。它是单步、启发式的。

V2.0 引入了**卡尼曼式双系统门控**：System1 快直觉、System2 慢深思，按情境分配认知资源；并叠加**量子启发式叠加决策**——测量前同时持有 N 个候选方案及幅值（confidence），用退火温度从探索收敛到确定，同族候选相互干涉增强 / 抵消，情绪外场调制温度与先验，成败回灌放大 / 衰减幅值。再配上**岛叶躯体标记**（Damasio 理论）把身体能量 / 疲劳 / 压力编译成潜意识 gut feeling 去偏置决策。决策从"一句话怎么回"升级为"多候选如何收敛 + 内感受如何偏置"。

### 5. 安全：从「反幻觉闸门」到「价值锚点常开」
V1.0 的安全靠 `touches_surface` 反幻觉闸门（回答必须落在检索到的知识面上）+ 前提一致性闸门（指令性建议做矛盾检查）。V2.0 把安全下沉到**层 -2 安全层**：一组**不可修改的价值锚点**常开，任何上层输出先过价值锚；每个象量还带 `safety_relevance` / `human_impact` 两个安全维度；并立下**诚实性纪律**——预测器 / 世界模型证据不足时如实返回 `low_confidence` 或 `None`，**绝不编造轨迹或硬猜**。

### 6. 工程纪律：从「防分叉」到「可证伪 / 可消融」
V1.0 的工程纪律重点是"单一真相源"——`desktop/` 下所有同名模块都是再导出薄壳，改动只在 `pasm/cognitive/` 做，避免历史上双向分叉导致的"桌面端长期在犯核心已修复的 bug"。

V2.0 把纪律抬到方法论层面：**契约先行、开关驱动、消融优先、异步写盘、可复现、回放验证**；每加一层必须有开关、有指标、有收益；所有新模块**默认全关**，由 `capabilities()` 诚实申报"当前到底开了哪些能力"。还提供了 `CognitiveKit` 三档门面（开箱即用）和 `CognitiveAssembler` 声明式流水线装配（自己攒流水线、依赖自动拉起、蓝图如实申报），让底座可被不同产品按需裁剪。

## 四、为什么用户 / 开发者需要用它

1. **断网可用、零 token 内核**：V2.0 的认知内核完全在连续潜向量空间跑，不产生任何文本、不调用 LLM、纯 numpy CPU 毫秒级。意味着你把"记忆 / 世界模型 / 决策"装进任意本地应用、嵌入式设备、隐私敏感场景，都不依赖云端和算力。
2. **诚实，不编造**：证据不足就如实说"我不知道 / 置信度低"，不会像裸 LLM 那样幻觉。价值锚点不可修改，保证 AI 不会越过安全底线。
3. **即插即用的认知底座，而不是一堆指令**：V1.0 已经证明"给应用装认知器官"比"写一堆 prompt"可靠；V2.0 把它做成独立包 + 三档门面 + 装配器，开发者几行代码就能给自己的智能体接上记忆图、反事实推演、双系统决策。
4. **可消融、可证伪**：每个能力都有开关、有指标。你可以关掉某层看系统是否退化，用消融实验证明"这层到底有没有用"——这对科研和工程排障都极其重要。
5. **跨平台、轻量**：纯 Python + numpy，Windows / macOS / Linux 一致，桌面端（PASM Studio）已实测三平台全量产物。

## 五、升级的意义是什么

- **从"单轮壳"到"多轮智能体"**：V1.0 解决了"AI 能不能记住你、按情绪回话"；V2.0 进一步解决"AI 能不能在脑内推演因果、用快慢双系统收敛决策、带内感受偏置"——这正是小 U / 智能体类应用"显得更聪明"的分水岭。
- **从离散符号到连续潜向量自组织**：记忆不再是一堆被检索的标签，而是会聚成吸引子、会睡眠重放、会恶性合并自检的神经网络，更接近人脑的长期记忆机制。
- **从"动作成功率"到"可推演的因果世界模型"**：V1.0 的世界模型只能给"这条路线可行性上界"；V2.0 能跑反事实、能预测下一步象量并自我纠错（RPE），让 AI 具备"如果…会怎样"的真正推演能力。
- **从"防分叉"到"可证伪工程范式"**：V2.0 的开关驱动 + 诚实申报把"AI 系统哪层有用、哪层是凑数"变成可测量、可回归的问题，是对"AI 黑箱不可解释"的直接反抗。
- **架构独立性**：V2.0 不与现役引擎耦合，现役产品零风险平滑演进，新项目直接吃底座——这是一次"换引擎不熄火"的升级。

## 六、对以后 AI 发展的影响和作用

1. **认知架构正从"模型附属"走向"独立底座"**：当下多数 AI 应用把记忆 / 规划 / 安全硬编码进 prompt 或业务层。PASM V2.0 证明认知能力可以**标准化、可插拔、可消融**地独立存在，这会推动"认知中间件"这一层在行业里成形。
2. **神经符号 + 象量空间是务实路线**：不追像素级世界模型（那是数十万 GPU 小时的量级），而是用连续潜向量 + 神经符号在 CPU 上跑出"够用的因果推演"——为**资源受限设备上的认知智能**提供了可复制范式。
3. **诚实 AI 与可解释 AI 的工程化**：价值锚点常开、证据不足如实拒绝、能力面诚实申报，这些不是口号而是代码结构。它给出了一个"如何让 AI 守边界、可被信任"的具体实现样本。
4. **类脑计算的"软件化"落地**：丘脑 / 脑干 / ACC / 岛叶 / 小脑 / DMN 这些脑区被映射成可开关、可测量的软件模块，并用双系统、叠加决策、睡眠重放等机制复刻其认知功能——为"软件定义类脑"提供了一条不像脑机接口那样高门槛的平民路径。
5. **可复现与回放验证成为 AI 系统标配的可能**：V2.0 把"可复现、回放验证"写进开发纪律，指向一个方向——未来的认知系统应当像数据库一样**可回放、可审计、可回归**，而不是每次推理都是不可复现的黑箱。

## 七、总结与选型建议

**一句话结论**：PASM V1.0 把"AI 应用该有认知器官"这件事做通了；PASM V2.0 把"认知器官该是通用、可插拔、可证伪、诚实、断网可用"这件事做扎实了。它不是又一个聊天壳，而是一套**让任何 AI 应用长出记忆、推演、决策与边界的工程底座**。

| 你的情况 | 建议 |
|----------|------|
| 想给现有产品快速加"记忆 + 情绪回话" | 直接用 V1.0 分层记忆 + `cog` 状态机，成本低、见效快 |
| 要建长期陪伴 / 决策型智能体，重视"会不会推演因果、会不会自我约束" | 上 V2.0 底座（象量记忆图 + 反事实 + 双系统 + 价值锚点） |
| 资源受限 / 必须断网 / 隐私敏感 | V2.0 零 token 内核是刚需，裸 LLM 做不到 |
| 做科研 / 需要证明"哪层有用" | V2.0 的开关驱动 + 消融优先是你的最佳实验台 |
| 现役 PASM Studio 用户 | 无需改动，V2.0 独立包与现役引擎单向隔离，平滑共存 |
