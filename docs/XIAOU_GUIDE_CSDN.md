# 小U 使用说明 & 功能说明（PASM Studio 内置 AI 伙伴 · v0.31.11）

> 小U 是 PASM Studio 内置的桌面 AI 伙伴：能对话、会思考、记得住你、有情绪，
> 本地运行保护隐私，还能在专业领域（开店 / 跨境电商 / 食品经营）给出"先核验再开口"的建议。
> 本文面向首次接触小U 的用户，5 分钟完成安装到第一句对话。

---

## 一、小U 是什么

小U 不是"套壳聊天机器人"，它背后是 PASM 认知引擎，具备五层能力：

| 层 | 能力 | 一句话解释 |
|---|---|---|
| 对话层 | 多轮对话、双脑协同 | 简单问题秒回；复杂任务自动"起草→自我评审→修正"后再回答 |
| 记忆层 | 长期记忆、关键事实 | 记得你的名字、偏好、聊过的事，下次打开还在 |
| 认知层 | 世界模型、情绪、规划 | 会主动反问、根据上下文调整语气（默认人设"温和沉稳"） |
| 工具层 | 联网搜索、代码执行、文件读写 | 能查最新政策、能算账、能把结果落成文件 |
| 专业层 | 领域顾问引擎（0.31.11 新增） | 先抽取你的前提、核验现行规则，再给建议；自相矛盾会被自检闸门拦下 |

**小U 与普通 AI 助手的区别，用一个真实例子说明：**

你说："我已有个体工商户营业执照，想开宠物店卖猫砂和冻干。"

- 普通 AI（用旧知识硬答）："小白可以先开个人店试水，跑通了再升级。" ❌（你已经持照，直接开个体店才对，个人店类目受限、不能进精选联盟）
- 小U（领域顾问引擎）：✅ 先识别"你已有执照"这一前提 → 注入 2025–2026 现行规则（0 元入驻、按 GMV 档收保证金、0 粉开播）→ 给出"直接开个体店"的完整路径，并提醒"冻干=宠物饲料，需供应商提供《饲料生产许可证》+质检报告"。

如果小U 内部生成了自相矛盾的建议（比如明知你有执照却推荐个人店），自检闸门会在回复里追加一段可见的"自检纠偏"，**追加不改写**——它不偷偷改话，而是把问题摆给你看。

## 三、首次配置：选你的"大脑"

小U 支持双引擎，可以只用其一，也可以混搭：

### 方案 A：本地引擎（隐私优先，推荐起步）

1. 安装 [Ollama](https://ollama.com)；
2. 终端执行 `ollama pull qwen2.5:7b`（约 4.7GB，另有 9b/12b 可选）；
3. 小U 设置里选择 **本地引擎 → qwen2.5:7b**。

特点：完全离线、对话不出本机；速度取决于你的显卡/CPU。

### 方案 B：云端引擎（能力优先）

1. 到 DeepSeek 开放平台申请 API Key；
2. 小U 设置里选择 **云端引擎**，粘贴 API Key；
3. 可调"思考预算"（think budget），控制复杂问题的思考时长。

### 方案 C：混搭（推荐长期方案）

- 日常聊天走本地模型（零成本、隐私）；
- 复杂任务（联网核验、领域顾问、长文写作）自动切换云端。

> 设置里还可以定制：**名字**（默认"小U"）、**人设**（默认"温和沉稳"）、**声音**、**是否自动朗读**等。

## 四、功能一览与使用方法

### 4.1 对话与思考
- 直接输入即可；复杂问题小U 会先"想一想"再答（界面可见思考过程）；
- **双脑协同**：重要任务自动走"起草→评审→修正"管线，闲聊则单次直出，不浪费等待时间。

### 4.2 长期记忆
- 告诉它"记住：我家猫叫团团，对鸡肉过敏"，它会存入记忆层；
- 下次问"团团能吃这个吗"，它记得上下文。

### 4.3 联网与工具
- 问"最新"类问题（政策、价格、版本）会自动联网核验；
- 能执行 Python 算账（如"帮我算这 5 个 SKU 的定价"）、把结果写成 Excel/文件。

### 4.4 领域顾问（0.31.11 核心新能力）
当前内置 3 个领域，命中即自动生效，无需任何开关：

| 领域 | 会做的事 |
|---|---|
| 抖音/电商开店 | 类目资质、0 元入驻、保证金档位、选品定价、广告法红线 |
| 跨境电商 | 海关登记、报关路径、资质链路 |
| 食品经营 | 许可证 vs 备案制区分、健康证、场地要求 |

触发方式就是正常聊天——比如问"我想开店卖宠物零食"，小U 自动进入顾问模式。
（这套能力是开源引擎 [pasm-domain-advisor](https://pypi.org/project/pasm-domain-advisor/)，声明式扩展新领域，欢迎关注。）

### 4.5 语音
- 内置语音合成（支持多种音色），可开启"自动朗读"；
- 桌面小人模式：小U 以常驻桌面的角色形象陪伴，支持唤醒。

### 4.6 知识库
- 把你的文档放进知识库，小U 回答时会检索引用——让它"懂你的业务"。

## 五、常见问题 FAQ

**Q1：安装后 360/杀软报毒？**
v0.31.10 起已加入完整的版本签名信息（VERSIONINFO）并关闭 UPX 压缩，最新版已大幅缓解。若仍被误报，请选择"信任本文件"，或向我们反馈：这是无害误报，安装包 SHA256 可在 Release 页核对。

**Q2：没有显卡/配置低，能用吗？**
可以。选云端引擎（DeepSeek Key）即可，本地模型不强制。

**Q3：小U 说的政策信息准吗？**
专业领域内，小U 会联网核验并标注来源；无法核验的内容会明确告知，而不是编造。但重要决策（如办证、签约）请以官方最新文件为准。

**Q4：我的数据会上传吗？**
本地引擎模式下，对话、记忆全部留在本机；云端模式下仅你主动发送的内容会经过所选云服务商。

**Q5：升级后设置会丢吗？**
不会。记忆与配置随版本保留。
