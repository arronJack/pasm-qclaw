# PASM 三方向整合路线图：多模态 · 量子策略 · 离散/线性分析

> 2026-09-09 立项。决策结论：**三个方向都加**，但加法不同、分期落地。
> 顺序：Phase A（数学分析脑）→ Phase B（多模态感知）→ Phase C（量子策略决策层）。
> 理由：A 是地基（表格/数据干活立刻受益、且为 B 的视觉数值分析与 C 的调度提供工具），
> B 是感知入口（体验最直观），C 是决策升级（依赖 A 的数值能力 + B 的多源信息）。

---

## Phase A · 离散与线性分析（数学脑）— 本期开工

**定位**：给 PASM 装上"会算"的脑子。现在做表格只是"生成数据"，加了这个就能"分析数据"。

**模块**：`pasm/cognitive/mathlab.py`（纯 numpy，无重依赖，桌面版可直接打包）

**能力清单**：
| 子域 | 能力 | 对接点 |
|---|---|---|
| 线性 | 矩阵运算、行列式/秩、线性方程组求解（Gauss 消元） | 数据建模 |
| 线性 | 最小二乘线性回归（斜率/截距/R²/残差）、多元回归 | 表格趋势分析 |
| 统计 | 均值/方差/分位数/相关系数矩阵、离群点检测（IQR/z-score） | genxls 产物"分析一下" |
| 离散 | 图分析：拓扑排序（依赖/流程校验）、最短路（Dijkstra）、连通分量 | agent_team 流程依赖校验 |
| 离散 | 排列组合、整数规划（小规模暴力/贪心）、马尔可夫链稳态 | 任务调度、记忆转移建模 |

**落地步骤**：
1. A1 `mathlab.py` 核心 API + 冒烟（本期）
2. A2 接入 genxls/表格续改：说"分析这个表格"→ 自动跑回归/相关/离群点，回复里给结论
3. A3 agent_team 流程编辑时用拓扑排序校验步骤依赖（环检测）

## Phase B · 多模态感知（眼睛 + 耳朵）

**定位**：从"只会打字"到"能看能听"。

**能力清单**：
| 子域 | 能力 | 技术路径 |
|---|---|---|
| 视觉输入 | 聊天发图/截图 → 看图说话、图表读数、UI 截图纠错 | Ollama 视觉模型（llava / qwen-vl），本地零成本 |
| 视觉输入 | `@图片.png` 与引用条打通（复用 v0.26.4 @引用 chip） | 图片不进正文，转视觉描述注入上下文 |
| 语音输入 | 按住说话 → ASR → 进输入框 | faster-whisper（本地）或云 ASR 降级 |
| 语音输出 | 已有 edge-tts，补情绪语调映射（开心→语速+音调） | 复用现有 TTS 链路 |
| 情绪联动 | 看到哭脸/风景图 → 情绪引擎联动 | mathlab 视觉数值 + EmotionSystem |

**落地步骤**：
1. B1 视觉：检测 Ollama 视觉模型可用性 → 发图路径进 `_brain`（多模态消息）
2. B2 `@图片` 引用接入 + 引用条显示图片缩略名
3. B3 ASR 输入按钮（先 faster-whisper 本地，慢机降级云）
4. B4 TTS 情绪语调映射（读 valence 调 rate/pitch）

## Phase C · 量子策略（决策层升级，纯软件模拟）

**定位**：不接量子硬件（现阶段无意义），做**量子启发式认知**——这恰好与 PASM 名字里的量子认知叙事闭环，也是与所有竞品拉开差异的一层。

**能力清单**：
| 子域 | 量子概念 | PASM 落地 |
|---|---|---|
| 叠加决策 | 测量前多态并存 | 决策时并行持有 3-5 个候选方案及幅值（confidence），对话中逐步"坍缩"：新证据到来按幅值重加权，最后选定。回复可展示"我脑子里同时有 3 个方案，倾向于…因为…" |
| 退火调度 | 模拟退火/量子退火 | agent_team 步骤排序与资源分配：以"总耗时+成员评分"为能量函数，退火搜索近优排程（替代贪心） |
| Grover 检索 | 振幅放大 | 记忆检索二段放大：向量粗召回 → 按"情绪相关性×时近性×重要度"构造振幅二次放大迭代，替代单次打分排序 |
| 干涉情绪 | 波函数叠加 | 情绪不是单值 valence，而是多频分量叠加（愉悦/激愤/期待相位），"干涉"后测量出当前主导情绪——让右侧内心面板显示更细腻真实 |

**落地步骤**：
1. C1 `pasm/cognitive/quantum_strategy.py`：SuperpositionDecision（候选幅值+证据坍缩）+ 冒烟
2. C2 接入 `_brain` 决策提示：候选方案幅值注入 system（"此刻我同时倾向 A/B/C，权重…"）
3. C3 退火排程接 agent_team（A 的图分析做依赖约束）
4. C4 Grover 式记忆检索接 memvec（v0.18.2 向量记忆就绪后）
5. C5 情绪多频叠加模型（右侧面板升级版，老的 valence 保留为投影值）
