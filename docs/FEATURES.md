# PASM Studio · 全部功能总览

> **会思考、会干活、会记住你的 AI 伙伴**（Windows 桌面版）
> 本文穷举 PASM Studio 的**全部功能**，按"你能感知到什么"组织，而非按代码模块。
>
> 产品形态：**双脑 + 认知执行皮层**
> —— 语言脑（DeepSeek / 本地 Ollama）负责听懂与表达，PASM 认知脑（本地离线）负责记忆、情绪与成长。

---

## 一、界面与交互

| 功能 | 说明 |
|---|---|
| **聊天 / 干活 双模式分栏** | 输入框上方 `[💬 聊天] / [🔧 干活]` 一键切换。聊天模式**绝不会**因为提到"做个应用/写个脚本"就擅自动手；动不动手由你说了算 |
| **多行大输入框** | Enter 发送 / Shift+Enter 换行 |
| **模型随时切换** | 顶栏可随时切换云端 DeepSeek / 本地 Ollama 各模型，选择会记住 |
| **会话列表** | 左侧历史会话，每条消息实时保存；新对话 / 切换 / 重启后都能点回旧会话继续 |
| **@ 引用与 / 指令** | `@文件` 直接引用上下文；`/` 唤出指令 |
| **桌面小人常驻** | 无边框悬浮小人，可拖拽、会自己散步；单击开口说话 + 头顶冒泡，双击打开完整对话窗 |
| **内心仪表盘** | 情绪（愉悦/唤醒/掌控/血清素）、记忆命中、性格漂移、发育阶段实时可视化 |
| **灰度思考显示** | 回复像 DeepSeek 一样：💭 灰度小字实时上屏思考过程 → 正文随后流出 → 最终态保留"灰度思考 + Markdown 正文" |
| **真实绘图与预览** | 聊天窗内直接渲染 Markdown、表格、代码块、图片 |

## 二、双脑架构与模型管理

| 功能 | 说明 |
|---|---|
| **语言脑可选** | DeepSeek（云端，强）/ 任意 OpenAI 兼容端点 / 本机 Ollama（离线，免费） |
| **本地模型自动发现** | 自动扫描本机 Ollama 已下载模型，优先挑中文 instruct 模型 |
| **多模型分工路由** | 闲聊走本地（快）、干活走云端（强）、评审走本地交叉校验；本地不可用自动回落 |
| **零 Key 可用** | 不填任何 Key 也能跑（本地演示模式：同样会记忆与成长，只是话术朴素） |
| **统一 LLM 网关** | 全部模型调用收敛到一个入口：重试 / 超时 / 降级 / 并发车道管理 |
| **前台优先调度** | 前台交互（聊天/干活）与后台任务（自学/自检）分车道，后台永不抢占你的响应速度 |
| **本地模型调优** | 走 Ollama 原生 `/api/chat` 精确控制上下文长度、驻留时长与思考链（兼容端点会静默丢弃这些参数） |

## 三、记忆系统（会记得）

| 功能 | 说明 |
|---|---|
| **工作记忆** | 正在聊的话题 + 正在推进的目标；退出时落盘，重启接得上 |
| **情景记忆** | 每 8 轮 / 新会话 / 退出时自动归档一段经历；跨会话按话题自动召回 |
| **程序记忆** | 干完活自动记一笔"要什么 → 用了什么 → 成没成 → 教训"；同类任务下次自动想起 |
| **记忆语义化标签** | 给每条情景记忆写"一句话标签"，检索时能回忆成自然语言 |
| **记忆路由器** | 在"关键词记忆 / 向量记忆 / 符号事实"之间路由，决定这次该想起什么 |
| **轻量向量检索** | 把"关键词命中"升级为"语义相似"，不引入任何新依赖 |
| **神经符号闭环** | 符号层验证过的**高置信确定事实**回写向量记忆，下次同类问题直接复用——既增强又防污染 |
| **项目级台账** | 每个项目（文案/表格/PPT/网站/软件）一本账：需求史 / 改动清单 / 冒烟结果 / 规则；续写时注入摘要 → 精准修改不跑偏 |
| **记忆可清空** | 数据全在本机，可随时清空重启 |

### 10.2 真实系统操作（v0.27.1）

| 功能 | 说明 |
|---|---|
| **说得出就做得到** | "删掉桌面上截图文件夹" → 真删（**移入回收站**可恢复） |
| **破坏性操作走确认** | "清理电脑垃圾" → 先扫描只读报告 → 弹窗确认 → 只清白名单临时目录里 2 天以上旧文件 |
| **正在用的跳过** | 被占用的文件跳过并如实计数，不假装完成 |
| **危险路径硬拒** | Windows / 程序目录 / 盘根**怎么问都不删** |
| **执行台账** | 每个真实操作记录 时间 / 对象 / 原因 / 结果；问"你真的删了吗"→ 直接亮台账 |

### 10.3 能力判定（非预设机制）

需求来了先判定，四选一：

```
DO      有真实工具/能力 → 直接做
LEARNED 学过 → 用学到的真做
LEARNABLE 不会但可学 → 先上网学，再真做
CANNOT  真做不了 → 说明真实原因（如"关机需要物理动作"）
```

> **防幻觉兜底**：没有真实执行成功，**绝不允许**说"已完成"。
> 绝不再编造"清理完了"这种没执行的话。

## 十一、任务执行与协作

| 功能 | 说明 |
|---|---|
| **任务规划器** | 复杂指令自动分解为可执行步骤并逐步执行；规则优先（零成本），确属复杂才用一次轻量 LLM 分解 |
| **难度自适应分裂** | 简单任务主体直接干；复杂任务拆子步骤逐个执行 + 台账 + 主体复核 |
| **输出验证器** | LLM 产出零成本规则校验：不通过 → 带问题重生成一次；仍不通过 → **如实降级输出**（绝不静默假装成功） |
| **结构化提示模板** | 让不同底层 LLM 在 PASM 框架下表现趋于一致（统一按 任务类型 → 目标/步骤/输出格式） |
| **多智能体团队** | 角色卡 / 流程编排 / 团队执行器——把任务分给多个角色协作完成 |
| **待办与提醒** | "帮我记：周三下午3点开周会" / "提醒我 14:30 喝水"，到期自动提醒 |
| **工作任务台账** | 聊天里让它做的工作，过程与结果**落在那项工作里**，而不是散在聊天流 |

## 十四、数据与隐私

- 记忆 / 配置 / 成长存档在 `%APPDATA%\PASMStudio`，**卸载不删除**，可随时清空记忆
- **单机运行**，不上传你的对话与文件（仅 LLM 调用本身走你配置的 API）
- 本地 Ollama 模式下**完全离线**，本机就是你的服务器
- 图片理解走本机视觉模型，不上云、零成本

## English Summary

**PASM Studio** is a Windows desktop AI companion built on a **dual-brain
architecture**: an LLM language brain (DeepSeek / any OpenAI-compatible endpoint
/ local Ollama) handles comprehension and expression, while the local,
offline **PASM cognitive brain** provides memory, emotion, personality and
long-term growth.

**Highlights**

- **Chat / Work dual mode** — it never starts working unless you switch modes.
- **Layered memory** — working, episodic and procedural memory, plus a
  neuro-symbolic loop that writes back only *verified, high-confidence* facts.
- **Real growth** — dopamine/serotonin emotion, drifting personality, and a
  developmental arc from infancy to adulthood, mirrored by the desktop pet.
- **Pet with self-designed behavior** — action weights are generated from
  personality, unlocked by growth stage, and refined by your feedback.
- **Voice in and out** — Windows SAPI speech recognition with automatic
  dialect fallback; character-aware neural TTS covering Cantonese, Taiwanese,
  Sichuan, Henan, Northeast, Shandong and Beijing accents.
- **Knowledge that stays whole** — self-directed web study stores full text,
  never discarding content when summarization fails.
- **Creation engine** — real image / video / comic-drama output with stepwise
  execution and same-image refinement.
- **Genuine system operations** — real deletions (to Recycle Bin), whitelisted
  cleanup with confirmation, hard refusal on dangerous paths, and an auditable
  operation ledger.
- **Capability broker** — every request is judged as DO / LEARNED / LEARNABLE /
  CANNOT. It never claims success without actually executing.
- **Developer toolchain** — multi-language real-file scaffolding, math brain,
  multi-agent teams, and self-healing loops.
