# PASM 是什么、能做什么、产生什么效果、生态一览

> PASM = Predictive Agent System with Memory（预测式记忆智能体系统）。
> 一句话：**给 AI 一颗"会长大的心 + 会记住你的脑"，让它从"聪明的工具"变成"你的伙伴"。**

## 一、它是什么（三层）
| 层 | 名称 | 定位 |
|---|---|---|
| 内核 | PASM 认知引擎 | 零 token 认知循环：感知→记忆→世界模型想象→规划→情绪/性格/成长（私有） |
| 产品 | PASM Studio（Companion） | Windows 桌面版：会聊、会成长、会干活的"小人"（发行于 pasm-qclaw） |
| 教学 | PASM-Lite | 同一理念的 ~260 行最小实现，供学习与验证 |

## 二、能做什么（能力清单）

**个体成长类**
- 从"幼儿期"开始，靠相处与自主学习**一步步长大**（经验制：幼儿→童年→少年→青年，体型随成长变化）
- 真实情绪/性格状态机：夸奖它会开心、冷落它会低落，**性格随经历塑形**
- 长期记忆三库（情景/语义/程序），记得你的经历、偏好、"它学过什么"

**对话与双脑类**
- 与本地 Ollama / DeepSeek 组成"左右脑"：LLM 负责说话与推理，PASM 负责记忆与自查
- 双脑总线 B3：LLM **主动调用** recall(回忆)/verify(自查)/learn(即刻学习)/mood(心情)，
  记忆按需回填 → **token 更省、更记得住、更少说错**

**干活类（它会帮你做事）**
- 待办助手：帮我记 / 提醒我 / 我有什么待办 / 完成 xx，**到期语音提醒**
- 找文件：在电脑里按名字/关键词找文件（只读）
- 分析文档：把方案/文档读进去，给出 概括/亮点/风险/改进建议
- 自动编程：说需求 → 它写 Python 脚本并**运行回显结果**
- 整点提醒：12:00 提醒吃饭、18:00 提醒下班（可扩展）

**自主生活类**
- 你不理它时：自己散步、**读书学习**、休息、打盹（作息真实）
- 自动化工作：10 分钟复习旧知识巩固、23:00 写成长日记、阅读频率自适应
- 可开启**自动上网自学**：每约 90 分钟自己挑一个主题上网学，提炼入库

**形态类**
- 桌面独立小人：全息科技风（可换萌糖/机甲皮肤）、会眨眼/说话张嘴/走路摆腿/打盹冒 Zzz
- 单击说话、双击开窗、按住拖动、右键菜单、托盘驻留

## 三、产生什么效果（体验 + 可度量）
- **体验**：一个会记得你、会长大、会主动提醒你、偶尔冒一句暖话的"桌面伙伴"，
  而不是用完即忘的聊天框。
- **可度量**：
  - 双脑总线后 **token/轮 目标 ↓50%**（记忆按需检索，不整段塞 prompt）
  - 长期记忆检索 2 万条级 ~0.6ms（引擎基准）
  - 情绪模块消融实验：去掉情绪奖励，探索成绩显著下降（多 seed 观察）
  - 成长：经验制可续档，知识库自动分类入库、重读巩固（置信度↑）、条目交叉联想

## 五、路线（短 → 中 → 长）
1. 短：自主任务循环（它自己定小目标→做→复盘）；verify 接真实只读技能
2. 中：表示级融合 R3（PASM 世界模型直接在 LLM 语义空间预测）
3. 长：真 3D 具身机器人 + 自我导向学习（研究型）
